# Kaleido · Material 3 Expressive Wallpaper Composer

A Material 3 Expressive wallpaper composer with constraint-based composition.

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Material Color Utilities (`@material/material-color-utilities`)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
